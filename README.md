# Lush-website

Enterprise Agricultural Export & Sourcing Web Platform for **Lush Trade Corp Tanzania Limited**.

## Overview
Lush Trade Corp Tanzania Limited is a premier export-import enterprise based in Mtwara and Dar es Salaam, Tanzania, engaged in sourcing, processing, and trading premium agro-commodities (Raw Cashew Nuts, Cashew Nut Kernels, Pulses, Kilimanjaro Coffee, Timber, and Industrial Imports) across Africa, Asia, and Europe.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Lenis Smooth Scroll, OGL (WebGL2 Raymarched Waves)
- **Icons**: Lucide React

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.
